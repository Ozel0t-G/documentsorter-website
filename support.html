Common questions

Does Clastra upload my files?

Not with on-device processing. If you explicitly select Claude, extracted text and folder context are sent directly to Anthropic using your own API key. Apple Private Cloud Compute follows Apple's system privacy model.

Why is a document waiting for review?

Low-confidence documents, missing destinations, possible duplicates, and mail attachments are held for review to prevent incorrect filing.

Where are passwords and API keys stored?

They are stored in your macOS login Keychain, separate from Clastra's local database.

Can Clastra overwrite my files?

No. Name conflicts receive a numbered suffix, and completed moves can be undone from the app.

Which files are supported?

Clastra handles PDFs, Word and RTF documents, HTML, common text and data formats, and source-code files. Scanned PDFs can use Vision OCR.
