Common questions

Does DocumentSorter upload my files?

Not when on-device processing is selected. If you explicitly enable Claude, extracted document text and destination-folder names are sent directly to Anthropic using your own API key.

Why is a document waiting for review?

Documents with low confidence, missing destinations, possible duplicates, or an email origin are held for review to prevent incorrect filing.

Where are passwords and API keys stored?

They are stored in your macOS login Keychain, separate from DocumentSorter's local database.

Can DocumentSorter overwrite an existing file?

No. Name collisions receive a numbered suffix, and completed moves can be undone from the app.

Which files are supported?

DocumentSorter handles PDFs, Word and RTF documents, HTML, common text and data formats, and source-code files. Scanned PDFs can use Vision OCR.
